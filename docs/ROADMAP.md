# WebSua - 云刷 · 路线图 (ROADMAP)

> 记录 WebSua 的演进方向与取舍。
> **P0** = 核心功能，优先做；**P1** = 媒体库增强；**P2** = 可选增强（**不许破坏零依赖**）；
> 最后一类是「公开仓库基建」——不是产品功能，但决定开源后能不能接住用户。

## P0 · 最值得补的核心功能

| # | 功能 | 实现要点 | 风险 / 注意 |
| --- | --- | --- | --- |
| 1 | **字幕支持** ✅ | 扫描时关联同目录同名 `.srt` / `.vtt`；前端 SRT→VTT 转换后 `<track>` 挂载；字幕开关 / 字号 / 延迟微调 | **不硬做 `.ass`**，明确提示不支持；**不引入后端依赖**（转换放前端）。**已于 v1.3.0 完成** |
| 2 | **播放队列 / 下一集** ✅ | 按目录顺序生成「下一集」；队列支持拖拽排序 / 清空 / 循环 / 随机；队列持久化 | 随机序**不能**作为会话恢复锚点（README 已踩过：恢复需先切确定性排序）。**已于 v1.4.0 完成** |
| 3 | **增量扫描 + 断点续扫** ✅ | 记录 `(path, size, mtime)`，只 upsert 变化项；持久化目录遍历栈实现断点；失败目录一键重扫 | 不解决「单次数小时」的硬伤，但能减少重复劳动与 UNIQUE 冲突。**已于 v1.5.0 完成**（失败目录一键重扫归入 #4） |
| 4 | **失败目录重扫 / 扫描差异报告** ✅ | 任务摘要保留 `failed_dirs`；提供「只重扫失败目录」；与上次扫描对比新增 / 消失 | **必须可观测**，绝不能静默丢弃。**已于 v1.6.0 完成** |
| 5 | **局域网访问密码 / 令牌** ✅ | 非 `127.0.0.1` 绑定时**强制**设置访问密码或 token；流 / API / 封面统一鉴权 | 只做**单用户门禁**，不做多用户体系。**已于 v1.7.0 完成** |
| 6 | **配置导入导出 / 备份** ✅ | 导出源配置（密码可脱敏或加密）、设置、收藏与进度；导入时校验 | 源于「测试清空用户数据」事故的教训：**可恢复性必须成为设计考虑**。**已于 v1.8.0 完成** |

## P1 · 媒体库增强

> **状态：六项主功能已全部完成**（v1.16.0 → v1.21.0）。
> 剩下「定时扫描」是可选项，本地工具场景优先级不高，暂未排期。

- [x] **文件夹树浏览** —— WebDAV 用户习惯按目录找内容，现有搜索 / 分页补不上这个心智。**已于 v1.16.0 完成**。
- [x] **视图过滤**：只看未看 / 只看有进度 / 只看收藏，与现有「历史」「收藏」打通。**已于 v1.17.0 完成**。
- [x] **批量操作**：批量收藏、批量重扫、批量移除索引（**只移索引，不删远端**）。**已于 v1.18.0 完成**。
- [x] **重复文件检测**：先做 `size + 文件名` 轻量版，**不上全量哈希**。**已于 v1.19.0 完成**。
- [x] **标签 / 自定义分类** —— 比固定「分类」灵活，但别做太重。**已于 v1.20.0 完成**。
- [x] **按源 / 目录聚合统计**：每个源多少视频、多少失败目录、最近扫描时间。**已于 v1.21.0 完成**。
- **定时扫描**：本地工具场景可选，**默认关闭**，且要能暂停。

## P2 · 可选增强（不许破坏零依赖）

- **可选 ffmpeg**：检测到就用 ffmpeg 生成精确缩略图与媒体信息；检测不到回退到现有浏览器截帧。**软依赖，不是硬依赖**。
- **多语言 UI**：公开后英文用户会来，至少英文 README + UI 预留 i18n。
- **观看统计 / 简单推荐**：按目录、最近观看、同源相似文件名，**不做算法推荐**。
- **HLS**：Safari 原生可播，Chrome 需 hls.js（会破坏零依赖）→ 见「明确不做」。
- **临时分享链接**：带过期 token，仅限局域网 / 自用场景。

---

## 明确不做 / 暂缓

| 项 | 原因 |
| --- | --- |
| `.ass` 字幕 | 解析复杂度高，投入产出比低；提示不支持即可 |
| HLS 作为默认播放链路 | Chrome 需引入 hls.js，直接破坏「零依赖」核心卖点；最多在文档里说明 |
| 多用户体系 | 单用户自用工具，门禁只需「一个密码」 |
| 算法推荐 | 无必要，按目录 / 最近观看足够 |
| 公网分享服务化 | 涉及安全与合规责任，不主动做 |

## 公开仓库基建（决定能不能接住用户）

- [x] **一键 demo** —— `python demo.py`：假 WebDAV + 独立演示目录 + 自动建源扫描 + 预置收藏进度。**已于 v1.9.0 完成**。
- [x] **CI 矩阵** —— GitHub Actions 跑 Windows / Linux / macOS × Python 3.9 / 3.11 / 3.13；浏览器测试用 Playwright 作为 **dev dependency**，不影响运行时零依赖。**已于 v1.10.0 完成**。
- [x] **Release 资产** —— 可复现源码 zip + `.sha256` + `CHANGELOG` + 自动化发布流程。**已于 v1.11.0 完成**。示例配置不再单独提供：备份导出的 JSON 就是格式示例，脱离真实数据源造一份假配置没有实际用途。
- [ ] **文档** —— 架构图。（英文 README **v1.13.0**；`CONTRIBUTING` / `SECURITY` / issue / PR 模板 **v1.14.0**；图文使用手册 + 截图 **v1.15.0**）
- [x] **`docs/lessons.md`** —— 把踩坑沉淀独立成篇，这是 WebSua 最有传播力的部分，别只埋在 README 里。**已于 v1.12.0 完成**。
- [ ] **安全默认复查** —— 默认 `127.0.0.1`；`0.0.0.0` 必须密码 / token；CORS 默认关；WebDAV 密码不返回前端、日志脱敏、数据目录权限提示。
